# Recruitment Candidate Portal

## 1. Project Overview
A web-based recruitment portal that allows candidates to register, manage their profiles, discover available job opportunities, and manage their applications through a centralized dashboard.

## 2. Problem Statement
Recruitment candidates often lack a centralized platform for managing their personal information and tracking multiple job applications. This portal provides candidates with a simple way to apply for jobs, monitor application progress, and update their employment status.

## 3. Target User

Recruitment agencies and their job candidates.

## 4. Core Features

1. Candidate registration and authentication
2. Candidate profile management
3. Job discovery and application
4. Application tracking
5. Application cancellation and employment status
